## 3. 过程中发现并修复的问题

1. **debug assets 平铺问题**：`assets.srcDir("src/test/resources/jm")` 会把 JSON 平铺到 assets 根目录（`assets/list.json`），运行时按 `jm/list.json` 读取报 FileNotFoundException（首测 `03-rank-month.png` 捕获到该错误态）。修正为 `assets.srcDir("src/test/resources")`。
2. **JmApp 需 open**：debug 变体 MockJmApp 覆盖要求 `open class JmApp`（已加注释说明仅 debug 使用）。

## 4. 边界与已知约束

- MockState/MockImages 为 debug 变体专用类；release 不参与编译（Manifest 不含 MockJmApp，DebugHooks 四钩子恒 null）。
- 乱序还原管线在模拟下按设计短路：模拟 photoId 均 < 220980（JmScramble 规则小 id 不乱序），单测固化该约束。
- 观察项（转 R2）：错误态文案直接透出异常原文（`模拟故障注入：断网（jm-mock）`），真实网络下即「Unable to resolve host」等技术细节泄漏——正是 R2 错误文案映射的对标修复点。
- 深链 Toast 在沉浸模式/截图时机下可能不可见，状态以 LogStore「jm-mock」行与实际故障行为为准。
