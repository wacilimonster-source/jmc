## 3. 过程中发现并修复的问题

1. **故障注入只覆盖 API 不覆盖图片**：MockImages.provide 不看 fault，断网时封面仍从模拟层成功返回，重试覆盖层无法触达（也说明此前轮次的断网复测对图片路径失真）。修复：OFFLINE 抛 IOException、SLOW 延迟 2s。
2. `ExperimentalFoundationApi` 漏 import / `matchParentSize` 误 import（编译期即红，已修）。

## 4. 边界与已知约束

- 评论区头像为非禁漫 /media 路径，走默认网络加载（模拟模式下 mock.jm.invalid 占位），不加重试覆盖层（低价值高频重组成本）。
- 长按复制使用 `combinedClickable`（ExperimentalFoundationApi），与书架卡片既有用法一致。
