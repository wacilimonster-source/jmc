## 3. 过程中发现并修复的问题

1. **选择层选择片段后原署名丢失**：初版 onPick 直接导航 `author/{片段}`，作者页拿不到原署名 → 片段切换条无法渲染（对标 PiKA 的 origin 参数缺失）。修复：路由加可选 `origin`，详情页选择层带 origin 导航。
2. **片段切换后 origin 被覆盖**：switchAuthor 调 loadComics 未传 originHint，_parsed 被重置为单片段 → 切换条消失。修复：switchAuthor 传 `_origin.value`。
3. **标题/原署名提示不跟随当前片段**：标题硬编码路由参数、提示行误用路由参数。修复：标题与提示均跟随 currentQuery / VM origin。
4. **收藏态未跟随片段**：LaunchedEffect key 从 author 改为 currentQuery。
5. 测试方法学修正：模拟器截图为 900px 缩略，而 UIAutomator 返回设备坐标（1080 宽）——此前多轮「点击无效」实为坐标错位；改用 ui_resolve 拿精确坐标后交互全部命中。

## 4. 边界与已知约束

- 署名样本作者字段样式千变万化，解析器以常见格式为准（联合/角色括号/顿号/×）；解析不确定时「完整署名」永远可用。
- pika 的「手动编辑入口」未实现（JM 作者维度搜索无 a 参数形态差异，暂无必要），记录为后续可选。
