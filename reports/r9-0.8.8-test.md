## 3. 过程中发现并修复的问题

1. **提示被 dismissed 初值吞掉**：`collectAsStateWithLifecycle(initialValue = true)` 在 DataStore 就绪前为 true，检测回调若同时检查 dismissed 会被早期状态压制且不再补发。修复：检测与展示条件解耦（回调只置 detected，横幅条件合并两者）。
2. **提示「切换滚动流」只写 pref 不改渲染**：本地 scrollMode 是组合状态，仅写 pref 下次进入才生效。修复：与面板「切换模式」同路径（scrollMode/zoom/pan/pref 全套同步）。
3. **mock 图片缓存键漂移盲区**：mock 尺寸升级后 URL 不变，Coil 磁盘缓存仍命中旧字节（诊断日志 decoded 720x1080 揭示）。修复：mock 图片文件名代数前缀（IMAGE_GEN），mock 形态变更时缓存键整体失效。
4. 新增 FQN 一处被 code-health 门禁抓出（PagerState 全限定），已转 import——门禁首次在自身开发中生效。

## 4. 边界与已知约束

- 阈值 2.2（h/w）为经验值：普通页漫（约 1.4-1.5）不触发，长条漫（≥3）稳定触发；介于 1.5-2.2 的高个头页不提示（不误扰）。
- 「忽略」为全局一次性（对标阅读引导），不按漫画记忆；重装或清数据后重新出现。
- 诊断日志行（reader-hint）保留在 debug 构建，release 无日志开销。
